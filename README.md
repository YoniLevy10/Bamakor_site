# Bamakor — אתר שיווקי

אתר תדמית לחברת "ש.נ. במקור ניהול ואחזקת נכסים בע״מ".

## טכנולוגיה
- HTML / CSS / JavaScript סטטי (ללא תלויות / build)
- עברית RTL
- אנימציות: scroll progress, 3D tilt, parallax, gradient mesh, cursor מותאם

## דיפלוי
מתארח ב-Vercel, מחובר לדומיין `bamakor.com`.

## קבצים
- `index.html` — האתר
- `logo.png` — לוגו (רקע שקוף)
- `favicon.png` — אייקון טאב
- `og-image.png` — תמונת שיתוף (וואטסאפ/פייסבוק)
